# Process diorama guide

Provide a clear 3–5-step process and receive one complete miniature scene, generated as a whole rather than stitched from stage images. Material, light, and spatial rhythm follow the subject.

[English README, examples, and installation](../skills/single-path-process-diorama/README.en.md) · [Agent entrypoint](../skills/single-path-process-diorama/SKILL.md)

Specify sequence, aspect ratio, materials, and lettering preferences. Inspect the actual image before relying on the prompt or file report. Complete branches, technical procedures, and exact engineering constraints require a suitable alternative representation.

This is an experimental candidate. Three completed image pairs and later text-only boundary trials are separate evidence sets. Additional bundled routing cases are reproducible specifications, not claims of completed image evaluations.
