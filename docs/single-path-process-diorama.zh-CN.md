# 微缩剧场使用指南

输入顺序明确的 3–5 步流程，输出一张完整的微缩场景。默认整图生成，材料、光线和空间随题材选择；不逐步生成再拼接。

[完整中文 README、三组案例与安装](../skills/single-path-process-diorama/README.md) · [Agent 入口](../skills/single-path-process-diorama/SKILL.md)

开始前只需给流程、画幅、材质和文字偏好。生成后先看成品，再查看实际提示词、约定和检查报告。需要精确分支或操作规程时改用合适的表达方式，不让艺术图冒充业务逻辑或工程证据。

当前为实验候选版。已经完成的三组图片与新旧版输入边界测试分开报告，见 [验证摘要](../skills/single-path-process-diorama/evals/VALIDATION.md)。待执行评测题不等于已完成的测试。
