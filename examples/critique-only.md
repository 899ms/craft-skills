# Critique-only example — Trailnest

> Fictional text-only case. The user requests diagnosis, not a replacement logo.

## Request

“Critique our current Trailnest mark only. Do not redesign it. It contains a complete location pin over a complete leaf, plus a small `T` cut into the leaf. We need to know why it feels generic and whether it will work as a 24 px toolbar icon.”

## Scope-respecting response

- Mode: `critique`
- Artifact status: geometry is described but no rendered file is available, so visual findings remain provisional

| Check | Finding | Confidence |
|---|---|---|
| Fusion | The pin, leaf, and `T` remain independently complete; moving one would not require redesigning the others. This is overlap, not semantic fusion. | High from description |
| Dominant silhouette | A standard pin likely dominates, making the mark read as a generic map product before a brand. | Medium until inspected |
| Reduction | The small `T`, leaf veins, and stacked boundaries are likely to close or disappear at 24 px. | Medium until rendered |
| Reproduction | Multiple nested shapes may become uneven when reversed or reproduced in one color. | Medium until rendered |
| Similarity | Pin-plus-leaf is a category cliché and warrants a competitor-shape check. | High as a risk, not legal clearance |

Decision: `revise`, pending inspection of the actual vector and 16–32 px renders.

Next review should verify one dominant silhouette, structural dependence between meanings, open negative space, and one-color reduction. It should also record obvious category neighbors.

Scope boundary: do not generate concept families, draw a substitute symbol, edit the file, or claim that visual QA passed. Ask for the vector or renders if the user wants evidence beyond this provisional critique.
