# recurring-character-diary-comic

[简体中文](README.md) | [English](README.en.md)

An experimental Skill for creating, auditing, and locally repairing 4–8 panel
diary comics around an existing authorized recurring character. It separates
locked story and visual contracts, risk-routed generation, deterministic
composition, contract QA, and editorial-layout review.
