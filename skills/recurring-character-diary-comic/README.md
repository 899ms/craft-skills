# recurring-character-diary-comic

[简体中文](README.md) | [English](README.en.md)

围绕已有且获授权的固定角色，创建、审核或局部修复 4–8 格个人日记漫画的 Skill。
它会锁定故事、角色身份、跨格状态和精确对白，按风险选择生成路线，再对实际成品
执行合同一致性与编辑版式两条独立验收。

支持 `Create`、`Audit` 和 `Repair`；不负责从零设计角色、科普解释漫画、通用 Meme、
模仿在世艺术家、使用未经授权的系列角色或代替用户发布内容。
