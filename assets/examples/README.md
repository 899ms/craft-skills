# Original visual examples

The process-diorama images are located in `skills/single-path-process-diorama/assets/examples/`
and indexed on the collection homepage. Three inspected process examples and a separate conceptual
cover retain their original generated bytes and are hash-pinned by the root release checker.
See the [skill's asset scope](../../skills/single-path-process-diorama/ASSET-LICENSE.md).

All artwork in this directory was created specifically for fictional teaching and regression cases in this repository. It does not reproduce or trace any logo, frame, thumbnail, screenshot, or other visual asset from the linked research videos.

- `handoff/` is the primary hero case: six original concept families, a selected `Relay Joint H`, a responsive micro mark, and a rendered QA board.
- `xiuyue/` is a script-safety case: the symbol combines a page contour with mountain shoulders while keeping the Chinese wordmark unmodified.
- `d-tool/` is a regression fixture: it demonstrates an iteration after a small-size failure and must not be presented as a hero identity or distinctiveness claim.
- `recurring-character-diary-comic/` contains generated-original, public-safe
  tutorial visuals: a reduced page-native cover and a deterministic diagram
  comparing three page skeletons. They do not include internal profiles,
  prompts, run records, private source panels, or publication authority.

The SVG files are editable source artifacts. The PNG files are fixed review renders or native-size regression outputs. Approved public assets are hash-pinned by `scripts/check_release.py`; changing an asset requires an intentional checksum update and visual review.

These original project assets are covered by the repository's Apache-2.0 license. Names and marks are fictional teaching devices and are not trademark clearance.
